# 打工赚钱计时器 · Android 原生版

一个帮助自己坚持上班的轻量、离线 Android APP。

## 用法

首次打开：输入月工资、每月扣除金额、每月工作天数、每天工作小时数；点击「开始赚钱」，屏幕会逐秒累计工资估算金额，变化数字有上滚效果。可以暂停/继续；点击「下班」并确认，将结束当天计时并保留记录。

**示例**：月工资 10000 元，扣除 2000 元，21.75 工作日，每天 8 小时；到手 8000 元，每秒 0.0127713921 元（内部计算使用 BigDecimal），满 8 小时为 367.8161 元。

## 功能

- 工资、扣除、工作天数、每日工时可修改；每日计时上限为设置的工时。
- 以 `SystemClock.elapsedRealtime` 为计时依据，锁屏后前台服务继续累计，并在通知栏显示状态。
- 今日计时、今日参考收入、当月折算收入、工作进度、近30日记录；按天保存。
- 计时到达每日上限自动停止；手动「下班」结束该自然日，下个自然日可重新开始。
- Android 8 及以上；本地存储，无联网、无账号、无广告。

## 编译

Android Studio 打开本项目，在 Java 17 / Android SDK 35 / Gradle 8.10.2 下运行 `gradle :app:assembleDebug`。

**只用手机**：上传项目到自己的 GitHub 仓库，确保 `.github/workflows/build-apk.yml` 位于仓库根目录。在仓库 **Actions → Build WorkMoney APK → Run workflow**，成功后在工作流详情的 **Artifacts** 下载 `WorkMoneyTimer-debug-apk`，解压后安装 `app-debug.apk`。如果工作流已配置为监听目标分支的 `push`，推送后会自动打包。

## 注意

- 金额是按工作时长折算的**估算工资**，不代表实际收入到账。
- 修改工资和工时设置时，之前记录的时间会按新的单价重新折算金额；目前不保留历史各期工资费率。
- 不同厂商的 Android 省电策略可能限制后台服务。计时中建议允许通知、勿强制结束前台服务，必要时在系统电池设置中允许后台运行。
- 如果手机重启，运行中的会话自动停止，尽量避免将关机时间计入工作时长；之后需要手动继续。
- 手机系统时间在计时中被手动改动，可能影响自然日划分；建议保持自动日期时间。
